# Neon Keep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Neon Keep — a static browser arcade with two independent games (Loophole Guardian, Reflex Survivor) under one shared retro theme, no server and no AI.

**Architecture:** Pure static site. Vanilla HTML/CSS/JS, no build step, no framework. Each game is its own page linked from a hub page. Shared behavior lives in `shared/` modules that attach to a single `window.NK` namespace. Scripts load as classic `<script>` tags so the site runs from `file://` and from any static host.

**Tech Stack:** HTML5, CSS3 (custom properties), vanilla JavaScript, Canvas 2D (Survivor only), WebAudio (sound), localStorage (scores). Tests: Node built-in test runner (`node --test`, zero dependencies) for pure-logic modules only.

**Spec:** `docs/superpowers/specs/2026-09-06-neon-keep-arcade-design.md`

## Global Constraints

These apply to every task. Copy names and paths verbatim.

- **No build step, no framework, no dependencies** in the shipped site. No npm install to run it.
- **No network calls, no AI, no backend.** Everything runs client-side.
- **Namespace:** every shared script starts with `window.NK = window.NK || {};` then attaches its API. Never overwrite `window.NK`.
- **Script load order on every page:** `store.js`, `audio.js`, `juice.js`, then the page's own game script. All via relative paths.
- **Dark theme only.** No light mode.
- **Brand name is exactly `Neon Keep`** in all copy.
- **Node-testable logic files use this UMD guard** so `node --test` can `require` them while the browser gets a global:
  ```js
  (function (root, factory) {
    const api = factory();
    if (typeof module !== 'undefined' && module.exports) module.exports = api;
    root.NK = root.NK || {};
    root.NK.<name> = api;
  })(typeof self !== 'undefined' ? self : globalThis, function () {
    'use strict';
    // ... pure functions ...
    return { /* exported functions */ };
  });
  ```
  Only `shared/store.js`, `games/guardian/guardian-logic.js`, and `games/survivor/survivor-logic.js` use this guard. All other scripts are plain browser scripts.

### Shared Interface Contract (the source of truth for parallel work)

Every Phase 1 task codes against these signatures. Do not change them without updating this section.

**`window.NK.store`** (`shared/store.js`):
- `get(key, fallback)` → parsed value or `fallback`. Wraps `localStorage.getItem` + `JSON.parse` in try/catch.
- `set(key, value)` → `boolean` success. Wraps `JSON.stringify` + `setItem` in try/catch.
- `isMuted()` → `boolean` (default `false`, key `"nk.muted"`).
- `setMuted(bool)` → void.

**Storage keys owned by games** (hub reads these to show scores):
- Survivor: `"survivor.highWave"` → number (higher is better, default `0`).
- Guardian: `"guardian.levelsCleared"` → number (default `0`), and `"guardian.bestQuestions"` → number (lower is better, default `null`).

**`window.NK.audio`** (`shared/audio.js`), WebAudio synth, no asset files:
- `init()` → creates the AudioContext. Call once on first user gesture.
- `play(name)` → plays a short blip. Names: `"click"`, `"win"`, `"lose"`, `"hit"`, `"dodge"`, `"levelup"`. Unknown names are ignored.
- `isMuted()` / `setMuted(bool)` / `toggleMuted()` → mirror `NK.store` mute state; when muted, `play` is a no-op.

**`window.NK.juice`** (`shared/juice.js`), DOM/util effects:
- `shake(el, intensity = 8, durationMs = 300)` → applies a shake animation to `el`.
- `flash(color = '#ffffff', durationMs = 120)` → briefly overlays a full-screen colored flash.
- `hitStop(ms)` → returns a `Promise` that resolves after `ms` (freeze helper).
- `typewriter(el, text, speedMs = 25)` → returns a `Promise`; types `text` into `el.textContent` char by char.

**`shared/theme.css`** CSS custom properties (define on `:root`):
- Colors: `--nk-bg`, `--nk-bg-panel`, `--nk-neon`, `--nk-neon-2`, `--nk-danger`, `--nk-text`, `--nk-muted`.
- Type/space: `--nk-font-display`, `--nk-font-body`, `--nk-radius`, `--nk-space`.
- Utility classes: `.nk-btn`, `.nk-panel`, `.nk-title`, `.nk-crt` (scanline overlay).

**Navigation convention:**
- Hub tiles link to `games/guardian/index.html` and `games/survivor/index.html`.
- Each game page has a back link with text `← Keep` to `../../index.html`.

  const api = factory();
